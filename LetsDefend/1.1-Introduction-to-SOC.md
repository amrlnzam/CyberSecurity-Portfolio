# 🛡️ 1.1 Introduction to SOC

Welcome to the first step of my career as a SOC analyst. This lesson provides an overview of the SOC structure and the essential tools used in a Security Operations Center.

### **What I am Learning in this Course:**
* **The Structure of a SOC:** Understanding how a SOC is organized.
* **Operation of a SOC:** How a SOC functions to monitor and analyze security.
* **SOC Tools/Products:** Introduction to core products like SIEM, Log Management, and EDR.
* **Effective Tool Usage:** How an analyst should use their tools to detect and respond to incidents.
* **Common Mistakes:** Identifying and avoiding frequent errors made by analysts.

### **Career Goal Focus:**
To progress as a SOC Analyst, I will focus on mastering these key tools:
1. **SIEM (Security Information and Event Management)**
2. **Log Management**
3. **EDR (Endpoint Detection and Response)**
